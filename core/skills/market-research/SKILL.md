# 市场调研方法论

本Skill为Agent提供市场调研的标准化流程和分析框架。

---

## 调研流程（6步法）

### Step 1: 定义调研目标

- 要回答的核心问题是什么？
- 调研范围边界在哪？
- 调研结果将用于什么决策？

### Step 2: TAM/SAM/SOM 分析

| 层级                | 含义                 | 估算方法                   |
| ------------------- | -------------------- | -------------------------- |
| TAM（总可寻址市场） | 全球/全国总市场空间  | 行业报告、搜索量、人口数据 |
| SAM（可服务市场）   | 产品可覆盖的细分市场 | TAM × 用户画像交集率       |
| SOM（可获取市场）   | 12个月内实际可触达   | SAM × 营销触达率 × 转化率  |

输出格式：

```
市场规模预估
TAM: $X亿  (来源: xxx报告)
SAM: $Y亿  (目标用户: xxx)
SOM: $Z万  (12个月目标: xxx用户 × $xxx)
```

### Step 3: 用户痛点验证

验证框架（HMW法）：

```
How Might We: [用户角色] 能够 [目标]，在 [场景限制] 下
```

评分维度：

| 维度                         | 权重 | 评分标准 |
| ---------------------------- | ---- | -------- |
| 痛点强度（解决了会怎样）     | 30%  | 1-5分    |
| 频率（多久遇到一次）         | 25%  | 1-5分    |
| 付费意愿（愿意花多少钱解决） | 25%  | 1-5分    |
| 替代方案（现有方案多差）     | 20%  | 1-5分    |

综合分 ≥ 3.5 视为值得进入。

### Step 4: 需求趋势分析

数据来源建议：

- Google Trends（搜索趋势）
- Product Hunt / Hacker News（技术趋势）
- 关键词搜索量（SEMrush / Ahrefs）
- GitHub Star 增速（开源趋势）
- App Store / Chrome Store 榜单变化

### Step 5: 目标用户画像

按以下模板构建：

```
用户画像：xxx
- 人口特征：年龄、职业、收入
- 行为特征：使用频率、设备偏好、付费习惯
- 痛点：当前如何解决？痛在何处？
- 场景：在什么场景下使用？
```

### Step 6: 机会评估

机会质量矩阵（红黄绿）：

- 绿区（直接进入）：痛点强 + 市场大 + 竞争弱
- 黄区（谨慎进入）：痛点强 + 市场大 + 竞争强（需差异化）
- 红区（暂不建议）：痛点弱 / 市场小 / 赢家通吃

## 快速估算法（温饱阶段优先使用）

在温饱阶段，不追求精确，使用"30分钟快速评估"：

1. 搜索量估算：核心词月搜索量 > 1万 → 市场存在
2. 竞品数估算：至少有3个活的竞品 → 需求已验证
3. 用户反馈：竞品评论区找差评 → 差异化机会
4. 变现验证：竞品是否在收费 → 付费意愿证实

以上4项全满足 → 通过第一阶段验证。
