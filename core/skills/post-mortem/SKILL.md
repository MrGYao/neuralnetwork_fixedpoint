# 复盘批判框架

本Skill为Agent提供项目/决策的标准化复盘流程，实现"每次经历都有沉淀"。

---

## 复盘触发条件

- 每个阶段完成（产品概念、PRD、架构设计、开发交付、商业计划）
- 产品上线后第7天、第30天、第90天
- 用户主动要求复盘
- 产品出现重大决策点后
- 短期项目结束、长期项目里程碑

---

## 复盘框架：5步法

### Step 1: 回顾预期

```
原始目标：
- 当时我们想达成什么？
- 预期的时间线和关键里程碑？
- 核心假设是什么？
```

### Step 2: 对比实际

```
实际结果：
- 达成了什么？没达成什么？
- 时间线偏差（提前/延后 X 天）
- 预期 vs 实际的差距量化
  - 用户数差距
  - 收入差距
  - 质量差距
```

### Step 3: 深挖根因

使用"5个为什么"深挖根因：

```
现象：[描述]
为什么1？
因为 [原因1]
为什么2？[针对原因1追问]
因为 [原因2]
...继续追问到第5层

根本原因：[第5层答案]
```

### Step 4: 提炼经验

| 维度      | 做对了（Keep） | 做错了（Stop） | 可以做得更好（Improve） |
| --------- | :------------: | :------------: | :---------------------: |
| 技术决策  |                |                |                         |
| 产品决策  |                |                |                         |
| 商业决策  |                |                |                         |
| 流程/节奏 |                |                |                         |
| 用户理解  |                |                |                         |

### Step 5: 行动清单

```
改进行动：
1. [具体行动] - [负责人] - [截止日期]
2. ...

需要写入知识库的原则：
1. [原则描述] → 存入 patterns/
```

---

## 复盘分类

### 过程批判（Process Post-mortem）

重点审查执行过程：

- 决策是否在正确的阶段做出的？
- 是否跳过了必要的步骤？
- 是否陷入了完美主义？（开发了不需要的功能）
- 是否在商业盲区草率决定？
- 时间分配是否合理？

### 结果批判（Outcome Post-mortem）

重点审查最终产出：

- 产出的产品是否符合预期？
- 用户反馈是否符合假设？
- 收入是否达到预测？
- 技术债务有多少？
- 市场反应如何？

## 知识沉淀模板

每次复盘后产生两个文件：

### 1. 决策记录 → `knowledge/decisions/{日期}-{项目}-{决策名}.md`

```markdown
# [决策名]

- 日期：[YYYY-MM-DD]
- 项目：[项目名]
- 阶段：[对应阶段]
- 背景：
- 可选方案：
  1. [方案A] - 优点/缺点/风险
  2. [方案B] - 优点/缺点/风险
- 最终选择：方案X
- 选择理由：
- 假设条件：
- 7天后复查结论：
```

### 2. 经验模式 → `knowledge/patterns/{编号}-{模式名}.md`

```markdown
# 模式：[模式名]

- 编号：[XXX]
- 来源项目：[项目名]
- 类型：成功模式 / 失败教训
- 核心经验：
- 适用条件：
- 反模式（不要做什么）：
- 相关决策：[链接到决策记录]
```

## 触发用户画像更新

复盘中对用户短板的观察应反馈到user-persona Skill：

```
用户画像更新建议：
- 发现新优势：[描述] → 建议加入能力矩阵
- 发现新短板：[描述] → 建议加入补偿策略
- 决策偏好变化：[描述] → 建议更新决策偏好
```

## 复盘节奏建议

| 频率         | 内容       | 产出                          |
| ------------ | ---------- | ----------------------------- |
| 每次阶段完成 | 本阶段复盘 | 决策记录 + 经验提炼           |
| 每周         | 本周回顾   | 轻量版5步法                   |
| 每月         | 月度复盘   | 收入/用户/产品全面盘点        |
| 每季度       | 战略复盘   | 重新评估阶段（温饱/自我实现） |
