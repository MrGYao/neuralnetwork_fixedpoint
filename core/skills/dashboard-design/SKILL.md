# 可视化仪表盘设计指南

本Skill为toolsmith Agent提供开发可视化面板的设计规范。

---

## 仪表盘类型

### 1. 收入仪表盘

**目标**：一眼看清收入和利润状况

**关键指标**：

| 指标         | 计算方式            | 可视化方式                  |
| ------------ | ------------------- | --------------------------- |
| MRR          | sum(所有订阅月收入) | 大数字 + 趋势线             |
| 总月收入     | MRR + 一次性收入    | 大数字                      |
| 月利润       | 月收入 - 月成本     | 大数字(绿色=盈利/红色=亏损) |
| 付费用户数   | 活跃订阅用户        | 数字 + 趋势                 |
| 用户获取成本 | 营销成本 / 新用户数 | 趋势图                      |
| 流失率       | 取消数 / 总订阅数   | 百分比                      |

**图表配置**：

- 收入趋势图：月收入折线图（6-12个月）
- 收入来源分布：按产品/渠道的饼图
- 用户增长：新增 vs 流失 堆叠柱状图

### 2. 创意管道看板

**目标**：管理创意从产生到上线的全生命周期

**看板列**：

```
[新创意] → [验证中] → [高优先级] → [开发中] → [已上线] → [盈利中]
                                          ↓
                                     [低优先级]
                                          ↓
                                      [已放弃]
```

**每张创意卡显示**：

- 创意名称
- 当前评分
- 预估收入
- 开发周期
- 进入管道的日期
- 标签（AI/工具/SaaS等）

### 3. 项目状态追踪器

**目标**：追踪所有活跃项目所处的阶段和进度

**展示信息**：

- 项目名称 + 所属产品
- 当前阶段（概念/PRD/架构/开发/部署/运营）
- 阶段进度（0-100%）
- 下一步动作
- 阻塞项（如果有）
- 最近更新时间

### 4. 中间件监控面板

**目标**：追踪opportunist Agent识别的可独立售卖的中间产物

**展示信息**：

- 中间产物名称
- 来源项目
- 变现方式（库/SaaS/模板等）
- 当前状态（已识别/开发中/已上线/已盈利）
- 上线后月收入
- 优先级

## 技术选型建议

基于用户技术栈（Python/TS），推荐技术栈：

### 方案A：纯Web（推荐用于内部看板）

```
前端：React + Recharts/ECharts + Tailwind CSS
后端：FastAPI (Python) 或 Next.js API Routes
数据库：SQLite / Supabase
部署：Vercel / Cloudflare Pages
```

### 方案B：CLI + Web（轻量起步）

```
先做CLI报告（Python Rich库），
收入数据 → 终端彩色表格+趋势图 → 快速上线
后续升级为Web版本
```

### 方案C：Notion/飞书 集成（最快）

```
通过API写入Notion数据库，
使用Notion的数据库视图作为看板
适合温饱阶段快速验证
```

## 设计原则

1. **一眼看清**：核心指标每秒可读，不超3个大数字
2. **先看后查**：优先展示趋势和异常，点击进入详情
3. **温饱阶段**：能用一个表格解决的问题不做图表，能CLI解决的不做Web
4. **统一配色**：绿色=好/增长，红色=坏/下降，蓝色=中性/信息
5. **响应式**：桌面端优先，移动端只保留核心指标

## 数据采集

收入数据来源：

- Stripe API → 实时收入数据
- App Store Connect API → 应用商店销售数据
- Google Play Console → Android销售数据
- Gumroad API → 数字产品销售数据
- 手动录入 → CL工具记录

建议统一采集层：

```
采集层 → SQLite/JSON本地存储 → 看板渲染
```

## 输出检查清单

每次开发看板工具时检查：

- [ ] 核心指标是否在首屏可见
- [ ] 数据刷新机制是否正常
- [ ] 异常值是否有醒目标识
- [ ] 是否支持导出（CSV/PDF）
- [ ] 加载时间 < 3秒
