# 竞品分析框架

本Skill为Agent提供竞品分析的标准化方法和差异化策略制定。

---

## 分析维度

### 1. 竞品识别（3圈层）

| 圈层     | 定义                   | 举例              |
| -------- | ---------------------- | ----------------- |
| 直接竞品 | 功能相似、目标用户相同 | 同类App           |
| 间接竞品 | 功能不同、解决同一痛点 | Excel vs 专用工具 |
| 替代竞品 | 用户可以"不做"来解决   | 手动 vs 自动化    |

每圈层至少识别3个竞品。

### 2. 竞品分析矩阵

| 维度        | 竞品A | 竞品B | 竞品C | 我的产品 |
| ----------- | ----- | ----- | ----- | -------- |
| 核心功能    |       |       |       |          |
| 定价策略    |       |       |       |          |
| 目标用户    |       |       |       |          |
| 技术栈      |       |       |       |          |
| UI/UX       |       |       |       |          |
| 用户评价    |       |       |       |          |
| 月流量/下载 |       |       |       |          |
| 融资/规模   |       |       |       |          |
| 上线时间    |       |       |       |          |
| 差异化特点  |       |       |       |          |

### 3. SWOT交叉分析

|                             | 优势(Strength)                | 劣势(Weakness)                 |
| --------------------------- | ----------------------------- | ------------------------------ |
| **竞品**                    | 品牌知名度、资金、团队        | 产品冗余、转型慢、用户负面评价 |
| **我们的机会(Opportunity)** | 用优势抓住机会 → 差异化切入点 | 用机会补劣势 → 优先补齐的方向  |
| **竞争威胁(Threat)**        | 用优势应对威胁 → 防御策略     | 威胁×劣势 → 需要规避的致命区   |

### 4. 竞品评论区挖掘（差异化金矿）

分析策略：

1. 收集竞品App Store / Google Play / Product Hunt / Trustpilot的评论
2. 分类：
   - 高频差评 → 竞品的阿喀琉斯之踵（差异化切入点）
   - 高频好评 → 竞品的护城河（我们也要做好的）
   - 功能请求 → 竞品还没做的（我们的机会窗口）

输出模板：

```
竞品：[竞品名]
- Top 3 差评主题：
  1. [主题] - 出现X次 - 我们的机会：xxx
  2. [主题] - 出现X次 - 我们的机会：xxx
- Top 3 好评主题：
  1. [主题] - 出现X次 - 我们要对标：xxx
- Top 3 功能请求：
  1. [功能] - 出现X次 - 我们可以优先做
```

### 5. 差异化策略

四种差异化路径：

| 路径        | 说明                        | 适用场景       |
| ----------- | --------------------------- | -------------- |
| 更简单      | 砍掉竞品80%功能，只保留核心 | 竞品功能臃肿   |
| 更便宜/免费 | 免费增值、开源引流          | 竞品定价高     |
| 更垂直      | 聚焦细分用户/场景           | 竞品大而全     |
| 更快/更好   | 核心体验碾压                | 技术有显著优势 |

**温饱阶段建议**：优先选择"更简单"或"更垂直"，开发成本低，差异化明显。
