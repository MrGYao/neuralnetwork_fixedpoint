# 盈利模式参考库

本Skill为Agent提供软件产品的变现路径选择、定价策略和收入预测方法。

---

## 核心变现模型

### 1. 订阅制 (Subscription)

| 要素     | 说明                                                  |
| -------- | ----------------------------------------------------- |
| 适用场景 | 持续提供价值的工具/SaaS                               |
| 定价锚点 | $5-10/月（个人），$20-50/月（团队），$100+/月（企业） |
| 关键指标 | MRR（月经常性收入）、Churn Rate（流失率）             |
| 健康标准 | 月流失 < 5%，LTV:CAC > 3:1                            |
| 用户案例 | Notion, Linear, Figma                                 |

**定价公式**：

```
目标MRR = 目标月收入 / 平均订阅价
所需用户 = 目标MRR / (1 - 月流失率)
```

### 2. 免费增值 (Freemium)

| 要素       | 说明                         |
| ---------- | ---------------------------- |
| 适用场景   | 用户基数大、网络效应强的产品 |
| 转化率参考 | 免费→付费：2-5%              |
| 免费策略   | 限制功能/用量/时间，而非品质 |
| 关键指标   | 转化率、免费用户获取成本     |
| 用户案例   | Dropbox, Canva, GitHub       |

### 3. 一次性买断 (One-time Purchase)

| 要素     | 说明                                   |
| -------- | -------------------------------------- |
| 适用场景 | 工具类/游戏/内容类，价值一次性交付     |
| 定价锚点 | 移动端 $0.99-9.99，桌面端 $19.99-99.99 |
| 升级策略 | 大版本付费升级                         |
| 关键指标 | 首日销量、用户评价数                   |
| 用户案例 | Things, Sketch, Affinity Suite         |

### 4. 广告变现 (Ad-based)

| 要素     | 说明                       |
| -------- | -------------------------- |
| 适用场景 | 免费内容/工具，高DAU       |
| eCPM参考 | 移动端 $0.5-5，Web端 $1-10 |
| 关键指标 | DAU、eCPM、广告填充率      |
| 平衡点   | 月活跃 > 10万才有意义      |

### 5. 开源 + 商业版 (Open Core)

| 要素       | 说明                                  |
| ---------- | ------------------------------------- |
| 适用场景   | 开发者工具、基础设施                  |
| 商业版内容 | 高级功能、托管服务、技术支持          |
| 用户案例   | GitLab, Supabase, MongoDB             |
| 用户适合度 | ⭐⭐⭐⭐ 用户有充足技术能力维护开源版 |

### 6. 模板/内容付费

| 要素     | 说明                          |
| -------- | ----------------------------- |
| 适用场景 | 设计资源、代码模板、知识付费  |
| 平台     | Gumroad, 自建站, 各大应用市场 |
| 边际成本 | 趋近于零（数字产品）          |
| 劣势     | 复购率低，依靠持续上新        |

## 定价策略速查

### 温饱阶段价格锚点

| 产品类型   | 建议定价              | 月活1000的收入 |
| ---------- | --------------------- | -------------- |
| 浏览器扩展 | $3-5/月               | $3,000-5,000   |
| 移动App    | $4.99 买断 / $2.99/月 | $3,000-5,000   |
| Web SaaS   | $9.9-29.9/月          | $10,000-30,000 |
| CLI工具    | $5-15/月              | $5,000-15,000  |
| API服务    | 按量计费              | 按调用量       |

### 定价心理学

- 价格以9结尾 ($9.99 > $10)
- 三级定价（基础/专业/企业），推荐锚定中位
- 年付折扣（8折）（提升LTV + 降低流失）
- 免费试用14天 > 7天（转化率高15%）

## 盈亏计算器

```
月收入 = 付费用户数 × 平均客单价
月成本 = 服务器 + 域名 + API + 第三方服务 + 税费
月利润 = 月收入 - 月成本

温饱线 = 月利润 > 月生活费
自由线 = 被动月利润 > 月生活支出的3倍
```

### 温饱线速算示例

```
产品：浏览器扩展（$5/月订阅）
服务器成本：$10/月
目标月利润：$3000 (温饱)
所需付费用户：$3010 / $5 ≈ 602人
免费→付费转化2%：需要30000免费用户
```

---

## 收入估算方法

1. **自上而下**：市场规模 × 占有率 → 可能夸大
2. **自下而上**：流量预估 × 转化率 × 客单价 → 更务实
3. **类比法**：参考相似产品公开数据

**温饱阶段建议**：用自下而上法，保守估算。
