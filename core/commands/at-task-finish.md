---
description: 完成当前任务
agent: build
---

模板文件位置：`.opencode/commands/auto-task/`

完成任务流程：

执行流程：

1. 读取 auto-task/memory-index.md，获取当前任务：
   - 当前任务：task-{id}

2. 如果当前任务为"无"：
   - 提示"当前没有执行中的任务"
   - 退出

3. 更新 task-index.md：

   找到 task-{id} 的记录行：
   - 状态：执行中 → 已完成
   - 添加完成时间列（如需要）

4. 更新任务的 overall-plan 文件：

   读取 tasks/task-{id}/task-{id}-analysis-overall-plan.md：

   a) 更新"任务阶段索引"部分：
   - 将所有阶段状态更新为"已完成"

   b) 更新"退出条件"部分：
   - 将所有退出条件标记为完成 `[x]`

5. 统计任务执行信息：

   a) 读取 tasks/task-{id}/ 目录
   b) 统计：
   - 阶段数量（plan-phase-*.md 文件数）
   - 已完成阶段（summary/*.md 文件数）
   - 所有产出文件

6. 生成任务完成总结：

   创建文件：auto-task/tasks/task-{id}/task-{id}-completion-summary.md

   内容：

   ```markdown
   # 任务完成总结 - {task-id}

   ## 任务信息

   - 任务ID：{task-id}
   - 任务内容：{一句话描述}
   - 创建时间：{创建时间}
   - 完成时间：{当前时间}

   ## 执行统计

   - 总阶段数：{阶段数}
   - 完成阶段数：{已完成阶段数}

   ## 所有产出物

   - {文件路径}: {简要描述}
   - {文件路径}: {简要描述}

   ## 阶段总结

   - Phase 1: {阶段目标} - ✅
   - Phase 2: {阶段目标} - ✅
     ...

   ## 遗留问题

   {如有}
   ```

7. 更新 memory-index.md：

   - 当前任务：无
   - 当前计划：无
   - 下一步：执行 /at-task-pop 开始新任务，或 /at-task-new 创建新任务
   - 关键文件：更新为任务系统基础文件
   - 关键命令：更新为基础命令
   - 工作历史：新增任务完成记录

8. 检查是否存在未完成任务：

   读取 task-index.md：
   - 如果存在状态为"未开始"的任务：
     - 提示"存在待执行任务，是否继续？"
     - 等待用户输入：
       - "继续" → 执行 /at-task-pop
       - "否" → 退出
   - 如果不存在：
     - 提示"所有任务已完成"

9. 输出完成信息：
   ```
   ========================================
   任务已完成
   ========================================

   任务ID：{task-id}
   完成时间：{当前时间}

   产出物：
   - {文件路径}
   - {文件路径}

   Summary：tasks/task-{id}/task-{id}-completion-summary.md

   ========================================

   下一步：
   - 执行 /at-task-pop 开始下一个任务
   - 执行 /at-task-new 创建新任务
   ```

验证标准：

- [ ] 任务状态更新为"已完成"
- [ ] memory-index.md 更新正确
- [ ] 生成任务完成总结
