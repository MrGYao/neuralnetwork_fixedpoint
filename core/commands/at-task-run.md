---
description: 执行任务（支持多任务并行，委派给专业 subagent 执行）
agent: build
subtask: false
---

模板文件位置：`.opencode/commands/auto-task/`

## 参数

```
/at-task-run [任务列表] [任务模式]

参数1 - 任务列表（可选）：
  - task-0,task-1,task-2  → 指定多个任务
  - task-0                → 指定单个任务
  - all                   → 所有待执行任务（默认）

参数2 - 任务模式（可选）：
  - auto   → 全自动模式
  - half   → 半自动模式（默认）
```

## 执行流程

### 1. 参数解析与初始化（主代理执行）

a) 解析任务列表：

- 如果指定 → 任务队列 = [task-0, task-1, ...]
- 如果省略 → 读取 task-index.md，任务队列 = 所有待执行任务

b) 解析任务模式：

- auto → 任务模式 = auto
- half 或省略 → 任务模式 = half

c) 更新 memory-index.md：

- 任务队列：task-0 → task-1 → task-2
- 任务模式：{auto/half}

d) 输出执行计划：

```
========================================
任务执行计划
========================================
任务队列：{task-0, task-1, task-2}
任务模式：{全自动/半自动}
并行策略：独立任务并行执行
========================================
```

### 2. 任务循环（主代理编排）

初始化：任务计数器 = 0

循环：

#### a) 取出下一个任务

- 如果队列为空 → 输出"所有任务已完成"，退出循环
- 当前任务 = 队列第一个
- 更新 memory-index：当前任务 = {task-id}

#### b) 标记任务为执行中

更新 task-index.md：状态 = "执行中"

#### c) 阶段循环

初始化：阶段计数器 = 1

循环：

##### i) 刷新记忆

执行 `/at-mem-fresh`

##### ii) 刷新计划（委派）

执行 `/at-plan-refresh`：

- Gap 分析：委派 `at-planner`
- 执行优化：委派 `at-executor`

##### iii) 执行阶段（委派）

执行 `/at-plan-run`：

- 执行步骤：委派 `at-executor`
- 评审产出：委派 `at-reviewer`

##### iv) 输出阶段执行结果

```
========================================
Phase {current} 完成
========================================
任务：{task-id}
产出：{产出文件列表}
验证：{验证结果}
========================================
```

##### v) 检查下一阶段

- 如果存在 phase-{current+1}.md：
  - 阶段计数器 += 1
  - 如果任务模式 = half：
    - 输出"阶段完成，请确认后继续"
    - 等待用户输入："继续" / "查看" / "退出"
  - 如果任务模式 = auto：
    - 输出"自动进入 Phase {current+1}"
    - 返回 i) 继续执行

- 如果不存在（最后阶段）：
  - 执行步骤 d) 任务整体评审
  - 退出阶段循环

#### d) 任务整体评审（委派）

执行 `/at-task-review`：

- 委派 `at-reviewer` 执行全面检查

#### e) 标记任务完成

执行 `/at-task-finish`

输出：

```
========================================
任务执行完成
========================================
任务 ID：{task-id}
总阶段数：{阶段计数器}
完成时间：{当前时间}

所有产出物：
- {文件路径}
- {文件路径}

建议验证：
- 手动检查关键产出物
- 运行相关测试
========================================
```

#### f) 检查下一任务

- 从队列移除当前任务
- 如果任务模式 = half：
  - 输出"任务完成，请确认后继续下一个任务"
  - 等待用户输入："继续" / "退出"
- 如果任务模式 = auto：
  - 如果队列不为空 → 返回 a) 执行下一任务
  - 如果队列为空 → 输出"所有任务完成"，退出

## 并行执行策略

当任务队列中有多个独立任务时：

```typescript
// 并行委派给多个 executor
;[
  Task({ subagent_type: 'at-executor', prompt: 'task-0 / phase-1' }),
  Task({ subagent_type: 'at-executor', prompt: 'task-1 / phase-1' }),
]
```

**条件**：

- 任务间无依赖关系
- 操作不同文件路径
- 任务模式 = auto

## 关键原则

1. **编排职责**：主代理只做调度、索引更新、用户交互
2. **委派执行**：思考→planner，执行→executor，评审→reviewer
3. **上下文隔离**：每个 subagent 独立上下文
4. **并行能力**：独立任务可并行委派
5. **模式检查**：half 模式在关键点等待用户确认
